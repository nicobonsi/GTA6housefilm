# Character reference photos

One folder per character id from `project.yaml` (e.g. `characters/hero/`).

For each person, 3-10 photos:
- 1 straight-on face, neutral light, no sunglasses
- 2 three-quarter angles (left and right)
- 1 profile
- 1-2 full body in the outfit they'll wear in the film
- Sharp, well lit, one person per photo, no heavy filters

Consistency of the face across shots is the hardest part of the whole project.
Good references here save hours of re-rolls later.

These files are git-ignored (see `.gitignore`) so they never reach GitHub.
