# Location references

One folder per location id from `project.yaml` (e.g. `locations/living/`).

For each room or exterior:
- 4-8 photos from the corners and the doorway, at chest height, lights on
- the same at the time of day you want in the film (dusk works best for the look)
- a slow 20-30 s phone video walking through the space (useful for a 3D scan)
- tidy up first: clutter turns into nonsense once the model stylizes it

Optional: a 3D capture (Gaussian splat) made with a phone scanning app lets you
render real camera moves through your actual house. See the main README.

These files are git-ignored (see `.gitignore`) so they never reach GitHub.
